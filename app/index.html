      Everything else is safe

      PowerPyx confirms that, apart from the one trophy above, nothing trophy-related is missable: all trophy quest-givers return after the story, optional missions that disappear do not affect trophies, and every collectible needed for a trophy also spawns elsewhere. Keep a manual save at the start and end of each chapter anyway — there is no mission replay.

      Single-source warnings

      TechWiser, cited by CryptoGames, adds that the stranger mission chains behind five hidden trophies have windows tied to story progress. That warning comes from one source only, so this guide lists it here rather than flagging those trophies as missable: start each stranger chain when it unlocks, to be safe.
